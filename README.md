# Superstore Sales Dashboard

## Project Overview

This Power BI dashboard analyzes Superstore sales data to provide business insights.

## Tools Used

- Power BI
- Power Query
- DAX

## Dashboard Features

- Sales Analysis
- Profit Analysis
- Category Performance
- Regional Performance
- Interactive Filters
